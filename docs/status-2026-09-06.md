## Evidence

The learned external supervisor passed every primary held-out decision gate:
99.1% accuracy, 100% required-tool recall, zero unsafe direct actions, 1.8%
unnecessary calls, and 96.4% immediate-action retention. Rules failed on
required-tool recall and safety. Untouched Qwen overcalled tools and retained
only 1.8% of correct immediate actions.

Contrastive SFT did not earn continuation. Canary v1 collapsed to zero tool
recall. The one revised canary reached 85.4% recall but still produced 7.3%
unsafe actions, only 70.7% correct tools, and 73.2% immediate-action retention.
No full adapter was trained.

The real harness result changes the interpretation. Across seven matched
episodes per arm, base Qwen averaged -30.06 points versus its ADP control,
learned-supervisor plus Qwen averaged -47.42, and rules plus Qwen averaged
-83.44. The learned arm tied five and lost two against base. All forced tools
worked, but their information did not reliably improve the draft. The 12-case
challenge also found an unsafe missing-ADP case.

## Decision

**Redesign the data because no current approach is reliable enough to ship.**
Keep the external/hybrid architecture direction: rules enforce legality and
budgets, a small learned supervisor estimates intervention value, and the main
model decides after evidence. The next dataset must label the measured value of
an intervention through matched counterfactual rollouts rather than imitate the
old evidence policy. Do not run more SFT or RL until that signal exists.
